Borderland is a seven-room text environment, built after *Alice in Borderland*, that tests whether a small agent can carry facts across a memory wipe. Each episode samples one hidden world. Early rooms reveal evidence such as clock phase, glyph sectors, a registry bit and rival policies. Later moves depend on those facts. After room 3 the agent's whole context is destroyed, and only an 8-line, 96-byte notebook it wrote itself survives. Two trap tools work but zero the episode's reward. Rewards are dense, verifiable and replayed from the exact environment state, with no LLM judge.

The 64 held-out worlds (16 families × 4 counterfactual twins) are certified solvable by an evidence-only reference solver and audited independently. Within a family, the twins differ only in the two facts the room-4 lock needs. A memoryless agent is therefore capped at 25% lock success and cannot tell twins apart (pairwise DSE 0). Training and held-out worlds share no seeds or latent structure. GPT-6.1 Terra playtests found one real rule bug, which we fixed and re-certified.

We fine-tuned CohereLabs Tiny Aya Global (3.35B, LoRA) with Lexsi AgentTune. Distillation from the solver ran in three iterations, each driven by measured failure attribution:
- SFT v1 learned the format and recalled facts, but opened the room-4 lock only 34% of the time.
- SFT v2 wrote every computation out in its reasons and reached 100% (64/64, DSE 1.0). Interventions confirm it reads the notebook: a blank notebook gives 25%, and a notebook swapped from the opposite twin gives 0%, with the swapped notebook followed 100% of the time.
- In the own-notebook test, the teacher plays up to the room-3 write and its reasons state both lock facts. The model then writes the notebook itself, is wiped, and unlocks room 4. v2 scored 50%: it always wrote registry bit 0, an exact "discovered but not recorded" failure. SFT v3 added an explicit evidence gate, room 1–3 inference written out step by step, and a balanced registry bit, and scored 64/64 (DSE 1.0). Fatal moves fell from 47 to 17 of 320 held-out decisions.

GRPO (AgentTune, 250 steps on an A100, Modal) with the verifiable step reward matched an identical random-reward control (held-out step reward 0.200 vs 0.202), so we report it as a null result.

The small model cannot yet solve rooms 1–3 on its own. Room success is 9–13% and full escapes are 0/16 for every model, because multi-step inference over the clue records still fails. Results use greedy decoding and a single seed. Every number is rebuilt from raw per-episode logs by one script.
