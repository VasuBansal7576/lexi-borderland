# Frozen-weight Tiny Aya baseline protocol

Declared before the first game inference. No environment rules, world manifests, reward weights, reference trajectories or model weights are changed by this evaluation.

- Model: official `CohereLabs/tiny-aya-global-GGUF`, `tiny-aya-global-q4_k_m.gguf`, revision and SHA-256 pinned in `models/tiny-aya-global/upstream.json` and checked after download. This is the instruction-tuned global model, quantized Q4_K_M; no project SFT or RL has run.
- Engine: installed llama.cpp 0.7.0, build 11669, commit 620d2225c, on local Apple Silicon. Only model weights and task artifacts inside this project are used; there is no remote model inference.
- Decoding: temperature0, seed42, JSON-object grammar, 1,024 maximum output tokens per action, 32,768 generated tokens per episode, native 8,192 context. JSON grammar only enforces syntax, not legal choices or correct answers. No retries with corrected answers, reference fallback or silent context truncation. Malformed actions consume ordinary environment calls. Model rationale is logged as an observable output, not assumed to reveal internal reasoning.
- Fixed public system manual: `public_rules.txt`. No sampled answers, latent seed, private manifest, reward, evaluator flags, reference planner or private tools are exposed in unassisted runs.
- Observation transmission uses exact JSON and lossless top-level deltas within each room, retaining every original tool result. Full state is sent on room entry. The model is told how deltas work. Full uncompressed public frames and exact requests are logged alongside each response. Repeated unchanged text is removed; evidence is never summarized by another model.
- Every episode starts a new inference process. At the room-3 seal, kill the inference server, reset the client conversation, restart the server (therefore erase KV cache and positions), and send only the fixed rules plus the normalized room-4 state with the actual eight-line notebook. No past model responses or evaluator diagnostics cross the boundary.
- Unassisted suite: four previously certified development worlds, seed0, phase0/1 crossed with registry bit0/1. They are paired diagnostic worlds, not four independent random seeds and not an untouched learning holdout. Fatal loss stops that episode. Rooms not reached remain not reached, never scored as tested successes or failures.
- Separate room diagnostics: replay a previously saved legal reference prefix to the start of rooms2..7; expose only its legal public conversation since the last wipe and notebook, then let the actual model act without assistance. Stop when it clears that room or fails. This is explicitly reference-prefix-assisted, not end-to-end model performance. In particular these probes contain a reference notebook and possibly earlier reference actions.
- Separate model-notebook diagnostic: legal reference prefix through the room-3 objectives, stopping BEFORE the reference notebook is written. The model sees the legal evidence and chooses its own actions and notebook. Upon exit the actual server is restarted; test its first memory gate with only its own note. This isolates retention given upstream evidence and is not an unassisted run.
- Preserve every attempt and exact inference response, usage, source hashes, prompt hash, model provenance, process IDs, actions, environment trace and failure. Replay environment transitions exactly. An inference/context error is reported as a harness/runtime limit, not a reasoning or memory failure.

Sources: [official GGUF weights](https://huggingface.co/CohereLabs/tiny-aya-global-GGUF), [official model card and native context](https://huggingface.co/CohereLabs/tiny-aya-global), [llama.cpp server interface](https://github.com/ggml-org/llama.cpp/tree/master/tools/server).

## Diagnostic-only stopping addendum

After observing the four unassisted runs, and before starting any room2..7 diagnostic inference, add an evaluator stop after eight identical action/output transitions. This avoids spending the entire remaining call budget on an already documented no-progress loop. It does not apply to the unassisted or model-notebook runs, alter game mechanics, choose an action, grant a reward, or turn a recoverable state into a terminal loss. Such results are labeled `diagnostic_stall_eight_identical_transitions`, distinct from an environment failure. The changed runner is retained in source; model prompt and decoding settings are unchanged.
